## Remaining open items

- The series page quotes 2500 or 4000 VAC isolation without assigning the exact AS-103 option; do not invent a working voltage.
- Primary through-hole routing direction, burden protection and open-secondary hazard require explicit circuit binding.
- Not bound (D069). The centre-tapped sibling Talema AS-113 (1:300CT, Lsec 200 mH min, 5.0 + 5.0 ohm max, 150 + 150 ohm nominal termination, Isec 50 mA max, 900 V-us max; pins 1 '+', 2 centre tap, 3 '-') would match the three-pin 3D package, and its facts are recorded here. It stays blocked because the primary is a conductor threaded through the 5.0 mm aperture, not a pad: a binding needs non-pad primary terminals that every design must connect (D052 open_mating_roles covers only optional mating contacts; an unconnected primary is a floating inductor that ngspice cannot solve), the sourced pin map covers pins 1-3 only so the pin-role check cannot cover the primary, and the runtime check needs one primary end on return with the other end and the centre tap isolated per probe, which the path probe cannot express without forbidding the centre tap in real designs. These need an owner decision and framework support, not a recipe workaround.

## Conflicts

- AS-103 is 1:300, 200 mH minimum, 10 ohm maximum and 50 mA secondary; the earlier 1:200 / 10 mH / 3 ohm / 75 mA defaults are incorrect for this reference.
- A three-pin illustrated center-tapped part cannot silently represent non-center-tapped AS-103.
- D069: spec text (S14 'summarizer reading') says pin 1 = primary input and pin 3 = primary return/secondary ground; the Talema drawing shows all three pins are secondary (1 '+', 2 centre tap on CT versions only, 3 '-') and the primary is the aperture conductor.

## Simulation blockers

- Physical/reference and primary-conductor binding conflict; open-secondary operation is hazardous.
