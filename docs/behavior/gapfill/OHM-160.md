## Remaining open items

- No actual clamp resistance,thermal resistance or full load-temperature derating established by this opened sheet.
- Forbid treating the3mohm assumedclamp as measured or the0.8factor as manufacturer derating.
- Small wire ampacity,installation category and creepage context must be checked separately.
- Connector has no built-in polarity;terminalnumbers follow library convention.
- Former simulation blocker resolved for the explicitly bound reference (2026-10-11, D068): Rating-critical operating-temperature/derating and validated resistance model unresolved. Resolution: Phoenix publishes no clamp/contact resistance for MKDS 1,5 (prior round; phoenixcontact.com still HTTP 403 here), so the default stays unbound. Explicit alternate Same Sky TB007-508 (archived manufacturer datasheet) publishes a per-contact 20 mOhm max contact resistance, rated current/voltage and -40..+105 C operating temperature for the same form factor (5.08 mm pitch screw terminal, horizontal wire entry, 1 solder pin per pole), so the resistance model is sourced and the temperature limit is bound. Derating remains unpublished and is stated as a limitation, as accepted for OHM-161.
- Derating curve (current vs ambient) not published by Same Sky
- Whether 105 C includes self-heating is not stated
- Default Phoenix MKDS 1,5 remains unbound (no published clamp resistance; Phoenix site 403)
- Library footprint must be the TB007-508 layout (1.6 mm holes, 4.90 mm row offset) for the alternate to apply

## Conflicts

- 400V is specificallyIII/2,not universal:III/3is250V;22Amaximumloadentry does not replace17.5Anominalrating.
- D068: Spec default ratings (17.5 A, 400 V III/2, Rclamp 3 mOhm assumed) are Phoenix MKDS; the alternate is 16 A UL / 18 A IEC, 300 V UL / 250 V IEC, 20 mOhm max. Not interchangeable values.
- D068: Several existing OHM-159 field_updates cite only a Conrad mirror (prior round finding); unchanged by this alternate.

## Simulation blockers

- None for the bound reference Same Sky TB007-508-03BE (explicit alternate) (former blocker: Rating-critical operating-temperature/derating and validated resistance model unresolved. Resolved 2026-10-11, D068).
