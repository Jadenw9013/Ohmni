## Remaining open items

- Current calculated from 36 W requires the applicable mounting and thermal conditions; no independent safe installation current is established.
- Thermal model for a high-current assembly is not bound (the sense attachment is bound by D072: two sense pins, WSBS8518...20).
- No destructive-failure transient model is sourced.
- D072: Vishay 30341 states 36 W at 70 C derated against ambient temperature only, with no busbar, heatsink or mounting condition; no installed or free-air safe current (sqrt(P/R) = 600 A) is accepted.
- Bolt-joint/contact resistance and sense-pin-to-element resistance are not published.
- Pulse and overload capability is given only by the online JouleWizard tool, not an archived document.
- Library sense-pin positions (+/-4.5 mm, UNCERTAIN in the 3D spec) differ from the 100 uohm drawing spacing B = 12.57 mm; the 3D geometry is unchanged.
- Three-sense-pin (...40/...80), low-TCR, tapped-hole and Sn-plated options are not bound.

## Conflicts

- D072: the record's earlier source (doc 30134) is the Cu-terminal base model with no sense pins; the two-sense-pin option the 3D spec models is the separate ...20 document 30341, which the binding cites.
- D072: the spec says derating runs from 100 % at 70 C to about 10 % at 175 C; 30341 tabulates -65 to +170 C and its chart line reaches 0 % at the axis end. The tabulated 170 C is used.
- D072: the spec says the 36 W rating holds for the datasheet busbar mounting; 30341 states no mounting condition (its derating axis is ambient temperature).
