## Remaining open items

- The spec's LQM21F / TDK MLZ2012 placeholders remain unbound; D072 binds the named Murata LQM21PH2R2MGEL as the 0805 multilayer reference.
- The Murata dynamic-model list (LQM21PN2R2MGH) lacks saturation-drop/rise definitions, temperature range and SRF; the LQM21PH reference specification bound by D072 states them.
- Coilcraft current is a reference heating point, not an absolute maximum.
- Former simulation blocker resolved for the bound reference Murata LQM21PH2R2MGEL (2026-10-11, D072): Unspecified default variant and incomplete rating conditions remain blocked. Resolution: Murata reference specification JELF243B-9129B-01 names the exact 2.2 uH 0805 part with tolerance, DCR, SRF, both rated currents with their definitions (+/-30 % inductance change; 40 C rise), a derating diagram and the -55 to +150 C range.
- Nonlinear inductance versus current, core loss and resonance are not modelled; the rated-current derating above 85 C ambient is not encoded.
- The wirewound 0805 row (Coilcraft 0805CS-150X_R_) remains a separate unbound alternative.

## Conflicts

- Original placeholder 0.2 ohm / 0.4 A / 0.5 A is not a rating table for either sourced variant.
- D072: the record's LQM21PN2R2MGH fields (1.3 A temperature rise, 0.45 A inductance change, 0.125 typ / 0.156 max ohm, Murata dynamic-model list) belong to the LQM21PN series and are not used by the LQM21PH2R2MGEL binding, whose facts use ref_* names.
- D072: spec placeholder DCR 0.2 ohm, Isat 0.4 A, Irms 0.5 A, Tmax 125 C (ASSUMPTION) vs LQM21PH2R2MGEL 0.39 ohm max, 0.88 A (+/-30 % L), 0.8 A at 85 C (40 C rise), -55 to +150 C.

## Simulation blockers

- None for the bound reference Murata LQM21PH2R2MGEL (former blocker: Unspecified default variant and incomplete rating conditions remain blocked. Resolved 2026-10-11, D072).
