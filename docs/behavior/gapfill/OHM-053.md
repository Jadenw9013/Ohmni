## Remaining open items

- Core loss, thermal resistance, interwinding capacitance and working-voltage/safety-insulation limits remain unsourced.
- Package pad permutation and parallel-group binding need runtime tests.
- The 750871111 alternative is not established by this source.
- Bound reference (D069): Wurth Elektronik 750311595 (WE-FB, EFD25, 12-pin SMD), the spec's own representative part. The record stays research_required in the protected spec, so the binding is reference-only and is not counted as audited simulable.
- Former simulation blocker closed only in the D066 sense (2026-10-11, D069): No safety or thermal acceptance for this transformer until working-voltage and loss limits are bound. Working voltage, core loss, thermal resistance and interwinding capacitance are not published on any of the 7 pages; the recipe states no safety, isolation or thermal acceptance and does not model core loss.
- Saturation behaviour: only a typical ISAT (16 A, |dL/L| < 20 %) is published; the model is linear.

## Conflicts

- Source 12 uH / 16 A / 0.4 uH leakage differs substantially from 100 uH / 3 A / 2 uH placeholders.
- D069: 3D spec OHM-053 says 'mounting: tht', but the 750311595 drawing is a gull-wing SMD part with an SMD land pattern (30.38 mm row span, 2.5 mm pitch, 3.76 x 1.52 mm pads).
- D069: turns_ratio_N1_N2_N3 has no unit, so it is re-recorded as winding_turns_relative (unit 1) for binding; the values are the same quote.

## Simulation blockers

- None for the bound reference (former blocker: No safety or thermal acceptance for this transformer until working-voltage and loss limits are bound. Closed only in the D066 sense, 2026-10-11, D069; the unclosed safety part is the recipe's first limitation).
