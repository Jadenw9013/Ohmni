## Remaining open items

- Enable slew,CT and QOD behavior require their own circuits/validation.
- Former simulation blocker resolved for the bound reference TPS22810DRV (2026-10-11, D074): Unknown central-pad electrical connection prevents runtime binding. Resolution: TI's own EVM schematic (SLVUAY7B Figure 1) wires the TPS22810DRV PAD (7) to GND (4); the recipe requires EP on the GND net. TI does not state the pad's internal connection, so no current is modeled through it.
- The TI model does not model temperature, thermal shutdown or Tj (its usage note 2); ratings come from datasheet facts.
- CT slew and QOD discharge are in the TI model but are not checked by the runtime probe (an operating-point RON check).

## Conflicts

- SOT23 current2A andtheta182K/W must not replace WSON3A@65C/theta74.6.
- D074: the class LOADSW model (VUV 2.54 V as UVLO, 1.0 V fixed EN threshold, no CT/QOD ports) is not this part; the binding uses TI's own model instead.
- D074: TI's model gives 80 mohm at VIN 12 V and 200 mA, inside the 25 C typ 79 / max 86 mohm row.

## Simulation blockers

- None for the bound reference (former blocker: Unknown central-pad electrical connection prevents runtime binding. Resolved 2026-10-11, D074).
