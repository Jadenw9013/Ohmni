## Remaining open items

- ESR/ESL versus frequency, leakage, bias-fit coefficients and effective capacitance at operating bias remain part-specific.
- A class bench using the supplied V0 law cannot establish a real MLCC DC-bias curve.
- DC-bias capacitance curve (not in the reference sheet; SimSurfing data not archived).
- ESR/ESL versus frequency and SRF remain unsourced for the bound part.
- Capacitance aging and the temperature curve shape inside the +/-15% X7R envelope.
- Former simulation blocker resolved for the explicitly bound reference (2026-10-11, D067): The exact default part voltage rating is not re-established by these general application documents. Resolution: Murata's per-part reference sheet for GRM32ER71E226KE15 (archived, sha 31eff98e0e21...) states the rated voltage (DC 25 V), capacitance and tolerance, X7R characteristic, operating range and an IR minimum for this exact part, closing the voltage-rating blocker for this explicitly bound reference. Bind it like OHM-024 (C + leak resistor card).

## Conflicts

- Do not transfer a curve or rating between different capacitance, voltage, case or dielectric variants.
- Spec default RLK 5e7 ohm is 22x the sourced IR minimum 50 ohm*F / 22 uF = 2.27e6 ohm, also below the class RLK floor 50e6 ohm; the binding uses 2.27e6 ohm (D067).
- Capacitance and DF for this part are specified at 120 Hz / 0.5 Vrms, not 1 kHz.

## Simulation blockers

- None for the bound reference Murata GRM32ER71E226KE15 (former blocker resolved 2026-10-11, D067).
