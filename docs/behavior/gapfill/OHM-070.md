## Remaining open items

- Proxy fit A remains an approximation for the actual dual-diode variants; shared package heating is not independent per die.

## Conflicts

- BAW56 is90V/2pF in the2022source, not the100V/1.5pF BAV99 default.
- 215mA single-diode current must not be used simultaneously for both junctions;125mA conditions apply.
