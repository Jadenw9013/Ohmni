## Remaining open items

- ESR/ESL versus frequency, leakage, bias-fit coefficients and effective capacitance at operating bias remain part-specific.
- A class bench using the supplied V0 law cannot establish a real MLCC DC-bias curve.
- Per-part spec sheet (test voltage for C/DF), DC-bias curve, ESR/ESL and ripple power limit (KEMET K-SIM data not archived).
- Former simulation blocker resolved for the explicitly bound reference (2026-10-11, D067): The exact default part voltage rating is not re-established by these general application documents. Resolution: The archived KEMET (YAGEO Group) X7R commercial-grade SMD datasheet C1002_X7R (2026-09-01) defines the exact ordering code (p2), shows C1812C 1 uF (105) available at 100 V (code 1) with thickness GG (Table 1B, p7), and gives series DF (p14) and IR (p15) limits and the -55..125 C range (p1). That establishes the 100 VDC rating for the exact orderable C1812C105K1RACTU. Murata's PIM database lists no 1 uF 100 V X7R 1812 part.

## Conflicts

- Do not transfer a curve or rating between different capacitance, voltage, case or dielectric variants.
- Spec RLK default 1e9 ohm agrees with the derived series IR minimum (1e9 ohm).
- Footnote 2 on the C1812C column header (KONNEKT) is ambiguous; the waterfall cell itself shows the standard part available.

## Simulation blockers

- None for the bound reference KEMET C1812C105K1RACTU (former blocker resolved 2026-10-11, D067).
