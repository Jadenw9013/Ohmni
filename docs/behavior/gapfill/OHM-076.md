## Remaining open items

- RthJA and maximum junction temperature are not tabulated; do not borrow the 5 mm lamp thermal model.
- Typical I-V/optical transfer and failure timing are not fully fitted.
- Former simulation blocker resolved for the bound reference Kingbright WP113IDT (2026-10-11, D070): The copied thermal parameters are unsourced for this rectangular lamp. Resolution: Kingbright's current 2 x 5 mm rectangular lamp WP113IDT (DSAF1525 V.10A, 2025) tabulates Tj 125 C, RthJA 580 C/W and RthJS 350 C/W (FR4, pad >= 16 mm2 per pad) with PD/IF/IFP/VR and a 25 C forward curve. The binding moves from W113HDT (no thermal data) to WP113IDT; the borrowed 5 mm thermal model is not used.
- Forward-current derating versus ambient is not encoded.
- Bicolor or stackable bar variants are not bound.

## Conflicts

- D070: the earlier reference W113HDT (bright red GaP: VF 2.25 typ at 20 mA, PD 120 mW, IF 25 mA) is a different die from WP113IDT (VF 1.9 typ at 10 mA, PD 75 mW, IF 30 mA); the recipe uses only WP113IDT values.
- D070: spec default if_max 20 mA (ASSUMPTION) vs the sourced 30 mA.

## Simulation blockers

- None for the bound reference Kingbright WP113IDT (former blocker: The copied thermal parameters are unsourced for this rectangular lamp. Resolved 2026-10-11, D070).
