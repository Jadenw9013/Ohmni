## Remaining open items

- Full current derating curve, reverse recovery, N/RS fit and thermal transient remain unimplemented.
- Other GL41 reverse-voltage variants need explicit type selection.

## Conflicts

- The spec names document 88548, which is a Schottky family. Standard recovery GL41 is document 88546; do not copy Schottky parameters.

## Simulation blockers

- The average-current derating curve must be implemented before claiming a complete thermal envelope.
