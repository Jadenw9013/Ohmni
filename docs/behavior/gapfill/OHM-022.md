## Remaining open items

- ESR/ESL versus frequency, leakage, bias-fit coefficients and effective capacitance at operating bias remain part-specific.
- A class bench using the supplied V0 law cannot establish a real MLCC DC-bias curve.
- DC-bias capacitance curve (not in the reference sheet; SimSurfing data not archived).
- ESR/ESL versus frequency and SRF remain unsourced for the bound part.
- Capacitance aging and the temperature curve shape inside the +/-15% X7R envelope.
- Former simulation blocker resolved for the explicitly bound reference (2026-10-11, D067): The exact default part voltage rating is not re-established by these general application documents. Resolution: Murata's per-part reference sheet for GRM155R71C104KA88 (archived, sha 530d3a4bf8e6...) states the rated voltage (DC 16 V), capacitance and tolerance, X7R characteristic, operating range and an IR minimum for this exact part, closing the voltage-rating blocker for this explicitly bound reference. Bind it like OHM-024 (C + leak resistor card).

## Conflicts

- Do not transfer a curve or rating between different capacitance, voltage, case or dielectric variants.
- Spec default RLK 1e10 ohm is 2x the sourced IR minimum 500 ohm*F / 0.1 uF = 5e9 ohm; the binding uses 5e9 ohm (D067).
- Class text quotes X7R DF 2.5% max (KEMET S8) as a generic ceiling; this part's own limit is DF <= 0.035 (3.5%).

## Simulation blockers

- None for the bound reference Murata GRM155R71C104KA88 (former blocker resolved 2026-10-11, D067).
