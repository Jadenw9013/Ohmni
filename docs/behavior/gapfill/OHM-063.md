## Remaining open items

- Solder-point temperature and actual board thermal path must be provided for thermal acceptance; no junction-to-ambient value is supplied for this variant.
- Nominal I-V/recovery parameters remain proxy assumptions.
- D072: the spec's research_required reason (ratings 'from the 1N4148 family scaled down: IF 150 mA assumed') is closed by Nexperia's current BAS516 single-type data sheet, which confirms the recorded BAS16_SER values (IF 250 mA, VR 100 V, Tj 150 C, pin 1 K / pin 2 A). The spec status cell is left for the owner to change to partial.
- No Rth(j-a) is published for this type (only Rth(j-sp)); ambient thermal acceptance needs the solder-point temperature.

## Conflicts

- BAS516 is an explicit package-matched alternative to the generic BAS16/1N4148WS placeholder. The source limit is 250 mA, while the original conservative 150 mA assumption is retained until binding.
- D072: spec placeholder IF 150 mA (assumed) vs sourced BAS516 IF 250 mA (FR4 standard footprint).

## Simulation blockers

None newly identified; other stated limitations remain.
