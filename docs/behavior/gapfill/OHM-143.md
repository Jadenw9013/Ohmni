## Remaining open items

- Motional C1/L1 are not specified; the class assumptions remain explicit and do not identify this crystal.
- Mechanical chamfer position is not a dependable pin1 identifier;source allows other chamfer corners.
- Package-axis permutation must be validated before a physical runtime binding.
- Former simulation blocker resolved for the bound reference Kyocera CX3225FB16000D0FZZH1 (2026-10-11, D073): Missing reference-specific motional parameters and unvalidated physical terminal permutation. Resolution: the Kyocera CX3225FB 8 pF specification tabulates ESR 50 ohm, C0 0.67~0.99 pF, C1 1.65~2.47 fF and L1 38.52~57.76 mH for this exact part (p3 Note 1), and its p4 lid-side drawing fixes the pad corners; docs/behavior/KYOCERA-CXFB-PERMUTATION.md maps manufacturer pads 1/2/3/4 to library terminals 2/3/4/1. The binding moves from ABM8 (no motional data) to the Kyocera part; the ABM8 facts keep their own scope and are not used.
- Library footprint (1.0 x 0.9 pads at +/-1.1, +/-0.8; 0.8 mm default height) differs from the Kyocera CX3225FB 0.7 mm body and about 0.9 x 0.8 mm pads; geometry not validated.
- Drive level is evaluated only from AC phasors (R1*|I_motional|^2 vs 100 uW); gain margin needs an oscillator loop and stays unknown. Temperature and aging are not modelled; ESR is a limit, not typical.

## Conflicts

- This chosen Abracon reference starts pin1 bottom-left; identity with the library top-left numbering would swap crystal and case-ground terminals.
- Sourced100uW drive ceiling is reference-specific;do not carry Epson200uW into this choice.
- D073: the spec's OHM-143 C0 'about 1 to 3 pF' (ASSUMPTION) vs the sourced CX3225FB16000 C0 0.67~0.99 pF.
- D073: the recorded ABM8 facts (ESR 70 ohm, C0 max 3 pF, CL 18 pF, -10..60 C, +/-50 ppm) belong to a different part; the recipe selects only facts scoped to CX3225FB16000D0FZZH1. The class CL default (18 pF) also differs from the bound 8 pF.
- D073: the class pin rule (A = pad 1, B = pad 3) uses library numbering; for the Kyocera part the crystal is on library pads 2/4 (manufacturer #1/#3), resolved by the permutation, not by changing the class rule.

## Simulation blockers

- None for the bound reference Kyocera CX3225FB16000D0FZZH1 (former blocker: Missing reference-specific motional parameters and unvalidated physical terminal permutation. Resolved 2026-10-11, D073).
