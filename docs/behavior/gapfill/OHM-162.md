- Pin-function/pin-coordinate map still requires archived manufacturer drawing;never treat shell as an automaticGNDshort.
- Primary PS-67643-002 text could be read through web search,but full content-hashed fetch timedout;its30mohm/contactcapacitance figures are not promoted here.
- Current-temperature-rise and contact-resistance model validation remain open.
- Former simulation blocker resolved for the explicitly bound reference (2026-10-11, D068): Exact source-backed pin-function and physical map plus validated contact model unavailable. Resolution: Default Molex 67643-3910 drawing/spec stay unreachable (molex.com fails from this environment). Explicit alternate Same Sky UJ2-AH-4-TH (archived manufacturer datasheet) numbers its four contacts 1..4 on the drawing (p2) and gives a contact resistance with test condition (30 mOhm max, terminal to mating plug at 20 mV/100 mA), 1.0 A, 30 Vac, -20..85 C (p1). That closes the contact model and the physical contact map. Signal names (VBUS/D-/D+/GND) are not printed and are NOT assigned (same treatment as OHM-163/166).
- Default Molex 67643-3910 drawing/PS-67643-002 still need a browser download
- Signal-function names unsourced from the alternate's drawing
- USB protocol, enumeration and power negotiation are not simulated.

## Conflicts

- D068: Entry/spec ratings 1.5 A, 30 V, -40..85 C are Molex 67643-3910 listing values; the alternate is 1.0 A, 30 Vac, -20..85 C.
- D068: Spec Rc 30 mOhm is an ASSUMPTION for the default; the 30 mOhm here is sourced only for UJ2-AH-4-TH.

## Simulation blockers

- None for the bound reference Same Sky UJ2-AH-4-TH (explicit alternate) (former blocker: Exact source-backed pin-function and physical map plus validated contact model unavailable. Resolved 2026-10-11, D068).
