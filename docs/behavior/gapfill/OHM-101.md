## Remaining open items

- The default ST L7805 D2PAK source timed out; its regulator binding remains separate and cannot use MOSFET drain/gate/source roles.
- Actual board thermal path, SOA and dynamic failure behavior remain unresolved.
- The package reference now has a sourced MOSFET example; this does not validate the regulator default or five-lead variants.
- Single-pulse table L0.47 mH differs from note2 L0.48 mH; retain that source discrepancy. Avalanche operation stays unsupported until a sourced pulse/SOA binding replaces the destructive-value guard.

## Conflicts

- This PDF gives94 W case power and1.5 K/W thermal resistance, which imply different limiting powers; enforce the lower.
- The Infineon product-page summary discovered during search reported110 W/1.4 K/W, whereas the archived2004 PDF gives94 W/1.5 K/W. Do not increase limits without a revision-specific binding.
- The class eas=0.53 J uses the typical destructive value as an operating ceiling. The primary source explicitly says this is outside rated limits. Its calculated thermal ceiling is150 mJ; do not use the old0.53 J acceptance expression.

## Simulation blockers

- The default regulator has no re-verified source/functional binding; keep that default blocked.
