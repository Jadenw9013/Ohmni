## Remaining open items

- Exact c-bmj-0102 drawing and GS-12-083 specification URLs returned 403; pin numbering, contact resistance, working voltage and exact family applicability remain open.
- Cat3 passive connector does not establish Ethernet PHY or PoE compliance.
- Former simulation blocker resolved for the explicitly bound reference (2026-10-11, D068): Missing exact terminal map/contact ratings; no PHY/protocol simulation. Resolution: Default Amphenol 54602-908LF drawing/spec (c-bmj-0102, GS-12-083) remain HTTP 403. Explicit alternate Adam Tech MTJ-880X1 (archived manufacturer drawing; same maker family as the bound OHM-170 MTJ-645X1) numbers all eight contacts on the recommended PCB layout (odd 1,3,5,7 one row, even 2,4,6,8 the other) and the front view (1..8), and gives 125 VAC RMS, 1.5 A, 20 mOhm max, -40..+85 C. Terminal map and contact ratings close; Ethernet PHY/PoE stay out of scope.
- Default Amphenol 54602-908LF drawing (browser download)
- Library footprint for MTJ-880X1 (hole sizes per drawing)
- No PHY/PoE model

## Conflicts

- 54602-910LF in the same source is ten-position; cannot substitute it for the eight-position 54602-908LF.
- D068: Entry family values (Amphenol brochure: 3 A continuous, 500 MOhm, 1500 V withstand, -65..125 C) do not apply to the alternate (1.5 A, 1000 MOhm, 1000 VAC, -40..85 C).
- D068: Spec S15 figures (1.5 A, 20 mOhm, 125 V AC) agree with MTJ-880X1 numerically.

## Simulation blockers

- None for the bound reference Adam Tech MTJ-880X1 (explicit alternate) (former blocker: Missing exact terminal map/contact ratings; no PHY/protocol simulation. Resolved 2026-10-11, D068).
