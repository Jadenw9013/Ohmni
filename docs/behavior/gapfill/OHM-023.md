## Remaining open items

- ESR/ESL versus frequency, leakage, bias-fit coefficients and effective capacitance at operating bias remain part-specific.
- A class bench using the supplied V0 law cannot establish a real MLCC DC-bias curve.
- DC-bias capacitance curve (not in the reference sheet; SimSurfing data not archived).
- ESR/ESL versus frequency and SRF remain unsourced for the bound part.
- Capacitance aging and the temperature curve shape inside the +/-15% X7R envelope.
- Former simulation blocker resolved for the explicitly bound reference (2026-10-11, D067): The exact default part voltage rating is not re-established by these general application documents. Resolution: Murata's per-part reference sheet for GRT188R71E105KE13 (archived, sha dd64337af2e0...) states the rated voltage (DC 25 V), capacitance and tolerance, X7R characteristic, operating range and an IR minimum for this exact part, closing the voltage-rating blocker for this explicitly bound reference. Bind it like OHM-024 (C + leak resistor card).

## Conflicts

- Do not transfer a curve or rating between different capacitance, voltage, case or dielectric variants.
- Spec default RLK 1e9 ohm is 20x the sourced IR minimum 50 ohm*F / 1 uF = 5e7 ohm; the binding uses 5e7 ohm (D067).
- Class text quotes X7R DF 2.5% max; this part's limit is DF <= 0.125 (12.5%).
- The GRT sheet gives IR > 5 ohm*F at 125 C (p5), 10x below the 25 C bound the card uses.

## Simulation blockers

- None for the bound reference Murata GRT188R71E105KE13 (former blocker resolved 2026-10-11, D067).
