## Remaining open items

- ESR/ESL versus frequency, leakage, bias-fit coefficients and effective capacitance at operating bias remain part-specific.
- A class bench using the supplied V0 law cannot establish a real MLCC DC-bias curve.
- DC-bias capacitance curve (not in the reference sheet; SimSurfing data not archived).
- ESR/ESL versus frequency and SRF remain unsourced for the bound part.
- Capacitance aging and the temperature curve shape inside the +/-15% X5R envelope.
- Former simulation blocker resolved for the explicitly bound reference (2026-10-11, D067): The exact default part voltage rating is not re-established by these general application documents. Resolution: Murata's per-part reference sheet for GRM033R60J104KE19 (archived, sha da3ec079ac4d...) states the rated voltage (DC 6.3 V), capacitance and tolerance, X5R characteristic, operating range and an IR minimum for this exact part, closing the voltage-rating blocker for this explicitly bound reference. Bind it like OHM-024 (C + leak resistor card).

## Conflicts

- Do not transfer a curve or rating between different capacitance, voltage, case or dielectric variants.
- Spec default RLK 1e10 ohm (class rule) is 20x above this part's sourced IR minimum 50 ohm*F / 0.1 uF = 5e8 ohm; the binding uses 5e8 ohm (D067).
- Spec ESR 50 mohm and ESL 0.3 nH remain ASSUMPTION; the part's only loss figure is DF <= 0.1 at 1 kHz.

## Simulation blockers

- None for the bound reference Murata GRM033R60J104KE19 (former blocker resolved 2026-10-11, D067).
