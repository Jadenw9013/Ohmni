## Remaining open items

- Per-segment thermal coupling, aggregate common-lead current and exact fit across current/temperature remain open.
- Multiplex duty does not permit exceeding the specified peak-current pulse conditions.
- Primary PD/IF table does not explicitly allocate the ratings per segment or as a package total. No such allocation is asserted.
- Former simulation blocker resolved for the bound reference Broadcom HDSP-5523 (2026-10-11, D070): Per-segment and common-lead aggregate power/current allocation is not established; do not use table PD/IF as a rated complete-display envelope. Resolution: The same Broadcom AV02-1107EN sheet covers HDSP-5523 (two digits, red, common cathode per digit, right-hand decimals, drawing F, 18 pins, not multiplexed), with every rating 'per Segment or DP'. Its pin map equals the archived DC56-11EWA map. The binding moves to HDSP-5523; each digit common is only a derived sum of its eight segment currents (no common rating is published).
- No package-total power, Tj or thermal resistance is published for HDSP-55xx; multi-segment self-heating acceptance stays unknown.
- Derating above the 55 C knee is not encoded; peak and multiplexed operation are not checked.

## Conflicts

- D070: the class pd_seg 105 mW is not supported (Kingbright table 75 mW; Broadcom 75 mW per segment).
- D070: Kingbright VR 5 V and peak 160 mA vs Broadcom VR 3.0 V (test only) and peak 90 mA; the binding uses Broadcom values only.

## Simulation blockers

- None for the bound reference Broadcom HDSP-5523 (former blocker: Per-segment and common-lead aggregate power/current allocation is not established; do not use table PD/IF as a rated complete-display envelope. Resolved 2026-10-11, D070).
