## Remaining open items

- ESL, frequency/temperature impedance fit and destructive failure behavior are not established.
- Select tolerance and termination options before claiming an orderable reference binding.

## Conflicts

- The generic ESR default differs from this 1 ohm maximum at 100 kHz; maximum is not a fitted nominal resistor.
- The fixed 3% reverse-voltage approximation is not the temperature-dependent MnO2 T491 limit.
- The existing bench can pass its old formula while that formula remains unsuitable for this reference family.

## Simulation blockers

- Runtime must use the scoped MnO2 reverse/temperature limits instead of the generic fixed 3% envelope.
