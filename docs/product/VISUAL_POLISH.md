Human-requested CUX-T05, 2026-10-11. Preserve the approved idea → plan → board flow.

Palette: ink #080f1b, raised surface #111e30, pale text #eef3fa, secondary #b5c4d6, action blue #83b8ff, copper #cda983. Keep semantic pass/warning/failure colors unchanged.

Type: Segoe UI Variable Text with local system fallbacks for controls; Segoe UI Variable Display for headings. No external font dependency. Use a compact 1.2 heading line height and readable body text.

Layout: left-aligned content, a generous idea composer as the focal point, compact inset feature summary, quiet disclosures. The landing retains its real interactive controller board as its distinctive object. Header and actions share one treatment across pages.

Plan critique: avoid introducing a second decorative PCB, artificial metrics, a new card grid or another sidebar. Preserve the existing recognizable logo. Replace diffuse neon glows and multicolor heading fills with solid, legible hierarchy; copper is a small material accent, never a verification signal.

No electrical, model, board geometry or generated-artifact behavior changes. This is visual polish, not independent product review or a usability study.
