# Module geometry attribution

The carrier footprints in this board adapt module outlines and header locations
from designs by **Adafruit Industries**:

- Adafruit I2S Microphone Breakout PCB / product 3421:
  https://github.com/adafruit/Adafruit-I2S-Microphone-Breakout-PCB
- Adafruit MicroSD SPI or SDIO Card Breakout PCB / product 4682:
  https://github.com/adafruit/Adafruit-MicroSD-SPI-or-SDIO-Card-Breakout-PCB

Adafruit's source licenses are Creative Commons Attribution-ShareAlike 3.0
Unported: https://creativecommons.org/licenses/by-sa/3.0/legalcode
The adapted module-outline/header geometry is distributed under those terms.
Changes by Ohmni: translate outlines to carrier-centered coordinates, invert Y,
apply microphone header mirror, add 1 mm courtyard allowance, and author
1.8 mm lands / 1 mm drills for the carrier headers. No endorsement is implied.

Module visual details and carrier assembly remain illustrative/unverified;
inspect the source CAD and actual modules before manufacturing and assembly.
