# Contributing to Ohmni

Start with [teammate setup](docs/TEAM_SETUP.md) and [AGENTS.md](AGENTS.md).
Coding assistants should also read [the AI handoff guide](docs/AI_TEAMMATE_HANDOFF.md).

Agree on an assigned task and file ownership, branch from current `origin/main`,
and open a PR. Keep production deployment, live AI/Sentry activation and merging
main with the owner. Do not commit secrets or private manufacturer PDFs.

The setup guide lists OS-specific commands, tests, native-tool prerequisites and
troubleshooting. In your PR include the problem, changes, exact verification
results and limitations. A skipped check is not a pass; self-review is not an
independent review. Keep unrelated changes out of the PR.
