# Ohmni reference implementation package

Start with `OHMNI_REFERENCE_IMPLEMENTATION_PLAN.md`.

Open `REFERENCE_ATLAS.html` in a browser to inspect all 158 entries against the supplied image.
The count is inventory entries, not an exact component count. Unknown identities and small subdetails are deliberately retained.

The three annotated PNG sheets are in `assets/`. The source image is the user-provided reference, not a newly generated render.

The plan separates the real Ohmni board, a rich illustrative reference scene, and a future independently verified denser electrical design.

Use the short Claude Code instruction in Appendix B after placing the package in the repository's documentation area.
